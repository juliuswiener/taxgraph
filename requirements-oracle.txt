# Das GETTSIM-Vergleichs-Oracle (oracle/.venv312, Python 3.12 — GETTSIM verlangt es).
#
# HIER IST DIE VERSION EIN ZAHLENWERT, KEIN ABLAUFDETAIL. GETTSIM ist das unabhängige
# Rechenmodell, gegen das unsere Catala-Regeln geprüft werden: tests/test_gettsim_crosscheck.py
# führt eine Allowlist bekannter Abweichungen (KNOWN_DEVIATIONS, u.a. GETTSIM-Bug #1209
# Splitting-Rundung), und eine NEUE Abweichung schlägt rot — das ist der Zweck des Gates.
#
# Ungepinnt (Audit dep-gettsim-oracle-unpinned) hiesse: eine neue GETTSIM-Fassung verschiebt
# die Vergleichsbasis stillschweigend. Entweder wird der Lauf rot, ohne dass sich bei uns etwas
# geändert hat — dann sucht jemand den Fehler an der falschen Stelle. Oder, schlimmer, ein
# behobener GETTSIM-Bug lässt eine Allowlist-Zeile ins Leere zeigen, und die deckt fortan eine
# ECHTE Abweichung mit ab, ohne dass es auffällt.
#
# 1.2.1 ist die Fassung, gegen die die heutigen Erwartungswerte erhoben sind (lokal gemessen
# 2026-08-18). Ein Wechsel gehört bewusst gemacht: Version hier heben, Crosscheck laufen
# lassen, die Allowlist gegen die neuen Ergebnisse durchsehen.
